# Virtual Reality

## Issues
Gebruik het "Issue sjabloon" om de issues aan te maken die beschrijven hoe de applicatie moet gaan werken. Gebruik hiervoor user-stories. Houd bij het schrijven rekening mee dat het duidelijk moet zijn voor een iemand anders. Het zou zo moeten zijn dat als jij het ontwerp maakt (alle issues beschrijft), dat een andere programmeur het zou moeten kunnen maken.

## Wireframes
Daar waar de user-story iets beschrijft dat zichtbaar is in de applicatie, moet er een wireframe in het betreffende issue bijgevoegd worden. Deze mogen eventueel met potlood en papier worden gemaakt.

## Application flow (navigatiestructuur)
De tekeneing van de navigatiestructuur moet in de desbetreffende issue opgenomen worden. 

## ERD
Een leesbare afbeelding van het ERD moet aan het issue ERD worden toegevoegd.

## Software / Hardware componenten
In het issue Software/Hardware moet je aangeven welke hardware en welke software je nodig hebt voor dit project. 

Wat hardware betreft, geef je aan wat voor een computer je gebruikt(processor, geheugen en opslag capaciteit).

Wat software betreft, geef je aan welke software je allemaal gebruikt inclusief versienummers. Denk ook aan het operating system dat je gebruikt.
