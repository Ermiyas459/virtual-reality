# Special IO

## ERD
Het ERD moet als bijlage aan het issue ERD worden toegevoegd

## Software / Hardware componenten
In het issue Software/Hardware dient de gebruikte Software en Hardware worden ingevoerd.

## Producten
De volgende producten moeten aanwezig zijn in de repository:
- Arduino Code
- Code voor het ophalen van de data van de Arduino (bijvoorbeeld Python of C#)
- Code voor het weergeven van de temperatuur
